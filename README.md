# 拾光 · 关注清理（Shiguang Follow Cleaner）

> **本项目主要由 AI 生成。** 代码、界面和文档大量由 AI 编写/辅助完成，不是专业软件团队的产品。请自行审计后再使用；非常欢迎有经验的大佬帮忙优化、重构和 Review。

一个面向 Windows 的抖音 / B站关注列表扫描、变量筛选和人工确认批量取关工具。所有登录态和分析数据只保存在本机，不上传服务器。

## 软件作用

关注列表变长以后，很难判断哪些账号已经长期不活跃、关系变淡或资料异常。“拾光”把关注列表完整读取下来，采集账号资料、关系、作品和状态变量，再用可组合的条件筛选；清理前必须由你人工确认，支持限速、分批、暂停和恢复。

它不会绕过平台安全验证，不会自动登录，也不会替你判断“应该取关谁”。最终决定权始终在用户手里。

## 主要功能

- 完整分页读取抖音 / B站关注列表，支持暂停、继续和断点保存。
- 每次扫描同步核验账号变量：作品数、最近更新、最近活跃、粉丝、等级、账号状态、互相关注、特别关注等。
- 筛选变量支持 AND / OR / 评分阈值，权重可调，变量可增删。
- 关注列表支持多选分类条件、表头排序、每页数量调整。
- 互相关注、特别关注、已收藏（星标）账号自动加入白名单。
- 白名单默认从关注列表、筛选结果、未匹配、选择和导出中隐藏；只有主动勾选“白名单（勾选后显示）”才显示。
- 批量取关前显示关注总数、筛选匹配、已选择、白名单排除和实际执行数量，必须再次确认。
- 支持按间隔逐个执行、分批冷却、连续失败自动暂停。
- 本地 JSON 数据、CSV 导出、清理历史；不包含遥测。

## 技术栈

- Electron 44
- Node.js 20+
- 原生 HTML / CSS / JavaScript 渲染层
- 主进程负责登录会话、平台请求、扫描队列、清理执行和本地持久化
- `src/shared/rules.js` 是浏览器与主进程共用的规则引擎

## 本地运行

```bash
# 需要 Node.js 20+，Windows 10/11
npm install
npm start
```

首次启动会打开平台登录窗口。登录态由 Electron 的持久化 Chromium 会话保存，后续尽量复用。

运行测试：

```bash
npm test
```

测试只使用假数据，不会访问真实账号。

